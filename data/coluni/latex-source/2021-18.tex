\textbf{(CAP-COLUNI 2021 -- Q18)} Em uma Olimpíada de Matemática realizada no país A, para o nível de Ensino Fundamental 2, os alunos tiveram que resolver a seguinte equação:
\[
x=
\left\{
\frac{
\left(\frac{1}{10}-\frac{1}{6}\right)\cdot(-0{,}9):\left(-\frac{3}{25}\right)
+\frac{0{,}2\cdot0{,}3}{3{,}2-2}
}{
\left(-\frac{2}{40/19}\right)
+\left[\left(-\sqrt[3]{-343}\right)+\sqrt{81}\right]^{-1/4}
}
\right\}^{3}.
\]

É CORRETO afirmar que o valor de $x$ é igual a:

\begin{enumerate}
	\item $-1$
	\item $1$
	\item $0$
	\item $\frac18$
\end{enumerate}
