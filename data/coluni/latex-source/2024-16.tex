\textbf{(CAP-COLUNI 2024 -- Q16)} Considere as afirmativas:

\begin{enumerate}[label=\Roman*.]
\item A raiz da equação
\[
5x-\frac32=\frac{2x-6}{4}
\]
é um número par.

\item O produto entre as raízes da equação
\[
\frac{3}{2x}+\frac{2}{x-1}=-1
\]
é positivo.

\item O maior inteiro pertencente ao conjunto solução da inequação
\[
-\frac{2x}{3}+5\geq-\frac72
\]
é um divisor de 4.
\end{enumerate}

É CORRETO afirmar que:

\begin{enumerate}
	\item Todas são verdadeiras.
	\item Todas são falsas.
	\item Apenas uma é falsa.
	\item Apenas uma é verdadeira.
\end{enumerate}
